PDF Text Extraction

pdfplumber extracts page-by-page text from each PDF document. We split and clean raw text into structured paragraphs while keeping track of the originating page numbers.

TF-IDF Vectorization

TF (Term Frequency) measures how frequently a word appears in a paragraph. IDF (Inverse Document Frequency) penalizes common words (like "the", "is") and boosts domain-specific keywords.

3

Cosine Similarity Ranking

Each paragraph and the search query are represented as mathematical vectors. Cosine similarity calculates the cosine of the angle between vectors: cos(θ) = (A · B) / (||A|| × ||B||) Values closer to 1.0 indicate high relevance.

4

Fallback Keyword Matching

If no paragraphs exceed the semantic threshold, an intelligent case-insensitive keyword scanner ensures verbatim mentions are never missed.
